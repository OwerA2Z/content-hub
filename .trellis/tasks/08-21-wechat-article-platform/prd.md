# 通用文章管理平台

## Goal

建设一个通用的文章管理后台：外部系统通过受保护的 HTTP API 上传文章，平台负责持久化、检索、预览、归档，并通过可插拔渠道适配器对接微信公众号。微信公众号是第一阶段渠道；账号不具备发布权限时，平台仍完整提供文章管理能力。

## Users and value

- 公众号运营者：查看、筛选、预览、归档文章，并按需创建微信草稿或发起发布。
- 外部内容系统/自动化脚本：稳定上传文章、使用幂等标识避免重复，并查询处理结果。

## Scope decisions

- 第一版采用“通用渠道适配架构 + 单公众号配置”；多公众号、多租户、团队权限放到后续阶段。
- 文章内容只读：不提供后台编辑器，标题、摘要、正文和图片以外部上传原文为准。
- 上传协议采用 JSON；正文为 HTML；图片以 URL 引用，首版不接收 multipart 文件、不建设素材库。
- 删除采用软删除/归档，默认列表隐藏归档内容，并保留恢复和追溯能力。
- 使用 PostgreSQL 持久化，服务端通过 repository 层隔离数据库实现。
- 微信动作与文章保存解耦，必须由后台用户明确触发；上传成功不自动发布。
- 渠道能力按账号权限探测：支持草稿则显示草稿动作，支持发布才显示发布动作；不支持时给出明确原因。
- 后台管理页面必须登录；后台会话与外部上传 API 的 Token 分离，发布等高风险操作只允许后台登录用户发起。
- 首次启动提供一次性管理员初始化向导；第一个管理员创建后关闭初始化接口，不开放公共注册。
- 管理员忘记密码时，可由服务器命令生成一次性恢复码；恢复码 15 分钟有效、只允许使用一次，Web 端完成密码重置。
- 微信草稿/发布采用任务状态展示，不要求浏览器请求一直等待微信接口完成。
- 同一文章同一渠道动作在未完成时不得重复创建操作；网络重试和重复点击必须返回已有任务。

## Requirements

### 1. 上传与 API

- 提供 Bearer Token/API Key 保护的文章上传接口。
- 必填字段：`title`、`content`、`contentFormat=html`；可选字段：`externalId`、`source`、`author`、`digest`、`coverUrl`、`images`、`metadata`。
- 以 `source + externalId` 实现幂等；重复上传返回同一平台文章 ID，不重复创建数据。
- 返回平台文章 ID、保存状态和渠道能力/对接状态。
- 对参数错误、认证失败、重复冲突、资源不存在、服务端异常返回稳定 HTTP 状态码和 JSON 错误结构。
- API 与后台读取同一 PostgreSQL 数据源，上传后可立即查询和预览。
- 上传接口具备请求体大小限制、基础限流和 API 版本前缀（`/api/v1`）。

### 2. 文章管理

- 支持文章列表、详情、HTML 预览、关键词搜索、状态筛选、时间排序、归档和恢复。
- 文章状态至少包含：`uploaded`、`draft_ready`、`publish_pending`、`published`、`sync_failed`、`archived`。
- 记录原始上传信息、渠道返回 ID、同步/发布时间、失败原因和最近一次操作。
- 默认查询排除归档文章；归档不删除原文和渠道审计信息。
- 记录上传、归档、恢复、创建草稿、发布和重试等操作审计。

### 3. 微信渠道适配

- 服务端封装微信公众号客户端，负责凭证、access token、草稿创建、发布提交、状态查询和错误映射。
- 微信适配器在创建草稿前负责将可访问的封面/正文图片 URL 转换为微信所需素材；图片处理失败只阻断微信操作，不影响本地文章保存。
- 支持人工创建草稿；账号具备发布权限时支持人工提交发布。
- 失败任务可在后台重试，重试过程不得泄露 AppSecret 或完整凭证。
- 微信凭证只存在服务端配置/密钥存储，不进入浏览器响应、前端代码或普通日志。
- 外部图片 URL 只允许 HTTP(S)，服务端访问时限制超时、响应大小，并阻止访问内网地址。

### 4. 后台界面

- 提供侧边导航、顶部工具栏、工作台、文章列表和文章详情/预览页。
- 工作台展示文章总数、近期上传数、待处理数、发布成功数、失败数等真实数据。
- 列表与详情提供加载、空状态、错误状态、操作确认和成功/失败反馈。
- 不提供 AI 创作入口、主动采集入口和后台正文编辑器。
- HTML 预览必须经过安全处理或隔离渲染，禁止文章内容执行脚本或读取后台会话。

## API 初步范围

- `GET /health`
- `POST /api/v1/articles/upload`
- `GET /api/v1/articles`
- `GET /api/v1/setup/status`
- `POST /api/v1/setup/initialize`
- `POST /api/v1/auth/reset-password`
- `GET /api/v1/articles/:id`
- `POST /api/v1/articles/:id/archive`
- `POST /api/v1/articles/:id/restore`
- `GET /api/v1/channels/wechat/capabilities`
- `POST /api/v1/articles/:id/wechat/draft`
- `POST /api/v1/articles/:id/wechat/publish`
- `POST /api/v1/articles/:id/wechat/retry`
- `GET /api/v1/operations/:id`

## Non-goals

- AI 生成、改写、润色。
- 主动抓取公众号、网站或其他平台内容。
- 首版素材文件管理、复杂统计、多人权限、多公众号租户和自动定时发布。
- 以微信公众号发布成功作为文章保存的前置条件。

## Acceptance Criteria

- [ ] 外部系统可通过认证 API 上传完整 HTML 文章。
- [ ] 重复提交同一幂等键不会创建重复文章，并返回稳定平台 ID。
- [ ] 刷新或重启服务后，文章仍可从 PostgreSQL 查询。
- [ ] 后台可列表、搜索、筛选、详情查看并按公众号样式预览文章。
- [ ] 后台可归档和恢复文章，归档文章默认不出现在普通列表。
- [ ] 后台根据公众号账号权限显示草稿/发布动作；无权限时给出明确提示。
- [ ] 微信草稿/发布失败时可查看原因并重试。
- [ ] 未登录用户不能访问后台管理页或发起草稿/发布/归档操作。
- [ ] 首次启动可创建唯一管理员，初始化完成后重复初始化返回冲突。
- [ ] 恢复码只在服务器命令中生成，过期或使用后不能再次重置密码。
- [ ] 微信操作以任务状态返回，浏览器刷新后仍可查询任务进度。
- [ ] 同一文章不会因重复点击或网络重试创建重复草稿/发布任务。
- [ ] 文章预览不会执行上传 HTML 中的脚本。
- [ ] 外部图片 URL 不会触发服务端访问内网或无限制下载。
- [ ] 关键写操作均有操作审计记录。
- [ ] API Key、AppSecret、access token 不出现在前端响应和普通日志中。
- [ ] `/health` 和数据库 readiness 检查返回准确状态。

## Deferred items

- 多公众号/多租户数据隔离与权限模型。
- 跨渠道通用素材库和素材生命周期管理；微信公众号适配器所需的最小图片转换属于首版发布链路。
- 定时发布、发布撤回和更复杂的渠道编排。
