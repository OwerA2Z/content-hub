# 后台使用手册

本文面向内容管理员和运营人员，介绍内容中台后台的日常使用方式。

## 1. 首次启动

首次访问后台会进入“创建管理员”向导：

1. 输入 3-64 位用户名。
2. 设置至少 12 位的管理员密码。
3. 确认密码后完成初始化。

初始化只允许创建一个管理员账号，完成后不会开放公共注册。

## 2. 登录与密码恢复

登录页支持用户名和密码登录。管理员忘记密码时：

1. 在部署服务器或应用容器中执行恢复码命令。

   ```bash
   npm run admin:recovery-code -- <管理员用户名>
   # Docker
   docker compose exec app npm run admin:recovery-code -- <管理员用户名>
   ```

2. 复制终端中显示的一次性恢复码。
3. 返回登录页，点击“忘记密码”。
4. 输入用户名、恢复码和新密码。

恢复码只显示一次，15 分钟内有效，使用后立即失效。重置密码后旧登录会话会自动失效。

## 3. 工作台

工作台用于查看内容中台的整体状态：

- 文章总数
- 微信草稿能力
- 微信发布能力
- 最近上传的文章
- 文章管理和 API 接入入口

如果微信公众号凭证未配置，草稿和发布能力会显示为“未配置”，但文章保存和 AI 接口仍可使用。

## 4. 文章管理

文章管理页面用于查看和维护已保存的文章：

- 使用标题或摘要搜索文章。
- 按 `uploaded`、`draft_ready`、`published`、`sync_failed` 等状态筛选。
- 勾选“查看归档”查看已归档内容。
- 点击文章打开右侧详情预览。
- 点击“复制文章内容”，将富文本复制到微信公众号编辑器；不支持富文本剪贴板时会自动复制纯文本。
- 可对文章执行归档、恢复、创建微信草稿、提交发布和失败重试。

文章通常由外部系统或 AI 通过接口上传，后台目前不提供复杂的富文本编辑器。

### 素材库

“素材库”是独立菜单，用于集中保存可复用图片：

- 上传 JPG、PNG、WebP 或 GIF 图片，单张最大 10 MB。
- 搜索文件名和标签，预览图片并复制素材 URL。
- 归档不再使用的素材；归档不会删除已关联文章。
- 在文章详情点击“从素材库选择”，即可把图片设为公众号封面。

素材文件保存在服务端的 `MEDIA_ROOT` 目录，Docker 部署时由 `media_data` volume 持久化。

### 微信操作状态

微信公众号操作采用异步任务：

1. 点击“创建微信草稿”或“提交发布”。
2. 系统立即创建 operation 任务。
3. 后台轮询微信公众号结果并更新文章状态。
4. 如果操作失败，文章会进入 `sync_failed`，可以点击“重试”。

发布前必须先创建草稿，并且公众号账号需要具备对应权限。

## 5. 内容规划

内容规划按三级结构组织连续内容：

```text
内容战略 → 内容系列 → 文章任务
```

### 内容战略

描述长期方向，例如目标受众、内容目标和主要内容支柱。

### 内容系列

在某个战略下建立连续主题，并设置系列顺序和目标文章数量。

### 文章任务

为系列创建下一篇文章的标题方向、核心问题、必须覆盖和必须避免内容。

AI 可以通过接口读取下一个文章任务及相关历史文章，再生成关联性更好的新内容。

## 6. API 中心

API 中心只负责给外部系统和 AI 提供调用信息：

- 查看 API Base URL。
- 查看文章、规划、AI 推荐和微信公众号接口目录。
- 查看每个接口所需的 Scope。
- 通过“管理 Token”入口进入独立的 Token 管理页面。

## 7. Token 管理

Token 管理页面专门负责访问凭证：

- 创建 Token 并选择 Scope 权限。
- 编辑未撤销 Token 的 Scope 权限。
- 查看 Token 名称、权限、前缀和创建时间。
- 撤销不再使用的 Token。
- Token 明文只在创建成功时显示一次。

建议按照最小权限原则创建 Token，并立即复制到安全的密钥管理系统。

## 8. AI 推荐文章

“AI 推荐”页面展示当天候选池：

- AI 可一次提交多篇候选文章。
- 系统自动比较已发布文章、草稿和同池候选。
- 每天推荐分数最高的几篇，并显示风险和警告。
- 接受候选后会保存为普通文章。
- 文章发布成功后，候选池会自动重新评估剩余文章。

接受候选只负责保存文章，不会绕过微信公众号草稿和发布确认流程。

## 9. 微信公众号配置

微信公众号凭证只配置在服务端，不会保存到前端代码：

```env
WECHAT_APP_ID=公众号AppID
WECHAT_APP_SECRET=公众号AppSecret
WECHAT_ENABLE_PUBLISH=false
```

配置后重新启动应用，在“微信公众号”页面查看草稿和发布能力。个人主体、公众号类型和微信平台权限可能限制草稿或发布能力，最终以页面能力检测和微信接口返回为准。

## 10. 常见问题

### 页面提示“未配置”

检查服务端环境变量是否已配置，并确认容器重启后环境变量已经生效。

### 文章上传成功但后台看不到

确认后台登录账号、查询 Token 和上传接口使用的是同一个环境；再检查文章是否被归档或查询条件过滤。

### AI 读取不到文章

AI 只读接口只返回已由微信公众号确认发布且未归档的文章。仅上传或创建草稿的文章不会出现在 AI 只读结果中。

### 微信发布失败

先查看文章状态和 operation 结果，确认封面 URL、公众号权限和 `WECHAT_ENABLE_PUBLISH` 配置，再使用“重试”。

更多接口细节见 [API 使用说明](./api.md)，生产部署见 [生产部署指南](./deployment.md)。
