# 文章上传微信草稿箱

## 目标
让管理员将平台已保存的单篇 HTML 文章及封面上传至已配置公众号的草稿箱，明确知道操作结果，不自动发布。

## 已确认事实
- 用户已同意在现有能力上补齐上传入口、配置提示、进度和失败反馈，并进入 Trellis 规划。
- 现有入口位于 `src/client/features/articles/ArticleDrawer.tsx:120`，仅在 capabilities.draft 为真时显示。
- `src/client/features/articles/useArticles.ts:107` 已有提交和轮询，但详情状态未同步刷新，轮询存在切换文章后的过期响应风险。
- `src/server/routes/channels.ts:20` 已有权限、封面及能力校验，返回异步操作记录。
- `src/server/channels/wechat.ts:42` 已有封面上传及 draft/add 调用，正文 HTML 直接透传，尚无正文图片转存。
- 相关前端文件存在未提交修改，实施必须保留。

## 需求
1. 文章详情常驻“上传微信草稿箱”入口；能力加载、配置缺失和错误有明确反馈；缺凭证不得产生虚假成功。
2. 复用素材库封面及公网封面 URL；缺少有效封面时指引补充，未保存的封面选择不得被误认为已上传。
3. 提交后显示处理中，阻止当前任务重复点击；成功或失败后同步列表和当前详情状态，展示草稿标识或错误原因。切换、关闭详情不得串写状态；超时提示后台仍可能处理中。
4. 保留现有单篇文章、HTML 正文、凭证环境变量和权限契约；核对正文图片同步所需转换，并在服务端完成必要处理，失败时不得静默丢图。
5. 微信公众号页面增加管理员配置 AppID、AppSecret；Secret 留空保留且不回显，服务端加密持久化，即时生效，页面配置优先于环境变量。支持测试已保存连接，不自动发布。
6. 更新使用及接口文档，关键逻辑使用中文注释。

## 验收标准
- 未配置公众号也能看到入口及配置说明，不能提交真实上传。
- 已配置时，具备封面的文章能提交任务，成功显示 draft_ready 和微信 media_id，失败显示实际原因并可重新操作。
- 正文和封面传给正确微信接口；正文有图片时具备对应转换及失败测试。
- 切换文章、关闭详情、轮询超时和查询失败不串写其他文章，不误报成功。
- 配置重启后仍保留；普通 Token 不可读写配置；响应不含 Secret；测试连接失败明确提示。
- 类型检查、构建及相关测试通过；实际页面检查入口和反馈。

## 不包含
批量上传、多公众号、自动发布、微信草稿编辑和覆盖更新、大规模重构。

## 外部验收条件
真实公众号权限、网络白名单及可用凭证由部署环境提供；真实草稿箱验收需要这些条件。实施期间已通过 curl 获取并核对官方草稿及正文图片文档，依据见 research/wechat-api.md。
