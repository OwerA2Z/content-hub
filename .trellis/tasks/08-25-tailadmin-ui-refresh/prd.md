# TailAdmin 风格后台界面

## Goal

将当前内容中台前端重构为更成熟的 TailAdmin 风格后台：导航清晰、数据表格可读、操作反馈完整、移动端可用，同时保持现有 API 和业务流程不变。

## Scope

- 使用 Tailwind CSS v4 + lucide-react 图标。
- 侧边栏分组、可折叠、当前页面高亮。
- 工作台统计卡片和最近文章。
- 文章管理表格、筛选栏、详情 Drawer/预览。
- 内容规划的战略/系列/任务工作流。
- API 中心的接口目录和 Token 管理。
- 微信渠道设置状态卡片。
- 统一 Empty、Loading、Error、Toast 和移动端布局。

## Non-goals

- 不修改后端 API、数据库和权限模型。
- 不接入 TailAdmin 私有付费资源或复制其品牌素材。
- 不新增复杂图表和数据分析模型。

## Acceptance Criteria

- [x] 四个主要页面可通过侧边栏清晰切换。
- [x] 文章列表使用可读的表格/列表布局，筛选、详情和操作反馈明确。
- [x] API 中心能展示接口地址、Token 状态和生成/撤销入口。
- [x] 内容规划能清晰表达战略 → 系列 → 文章任务层级。
- [x] 页面在桌面和窄屏下不溢出，按钮和表单具备可访问标签。
- [x] 现有 API 调用和登录流程不回归。
